# A Unified Reactivity Scale Predicts Nonenzymatic Phosphoryl Transfer and Nucleophilic Catalysis in Water

Data and scripts associated with the study:

**A Unified Reactivity Scale Predicts Nonenzymatic Phosphoryl Transfer and Nucleophilic Catalysis in Water**
Nat Schürmann, Yanyan Fei, Robert J. Mayer

Folder names refer to the corresponding sections of the Supporting Information (SI).

## Repository Structure

| Folder | Contents |
|---|---|
| `section2_analytics/` | NMR raw data (Mnova) for synthesis and characterization of the phosphorylating agents P5–P9 (SI section 2) |
| `section4_pka/` | NMR titrations (`p5_titration/`–`p7_titration/`) and DFT correlation for the pK<sub>a</sub> determination of P5–P9 (SI section 4) |
| `section5_6_kinetics/` | High-throughput kinetic datasets, one subfolder per phosphorylating agent, and the staged analysis notebooks (`stage1a`–`stage7`) up to the final k<sub>2,high</sub> selection and Brønsted analysis (SI sections 5–6) |
| `section8_lfer/` | LFER parametrization lg k₂ = N<sub>P</sub> + s<sub>N,P</sub>·E<sub>P</sub>: fixed scale from the high-throughput data (`lfer_analysis_v1_hte.ipynb`), combined high-throughput/literature scale used in the paper (`lfer_analysis_v2_combined.ipynb`), curated literature rate constants, and the resulting parameter tables with 95% confidence intervals (SI section 8) |
| `section10_nmrkinetics/` | NMR reference kinetics, raw data (Mnova, NS133 series) (SI section 10) |
| `section11_dft/` | ORCA output files (r2SCAN-3c) and the correlation of E<sub>P</sub> with computed Gibbs energies of hydrolysis (`DFT_correlation.ipynb`, reads a local copy of `lfer_analysis_v2_results.xlsx` from `section8_lfer/`) (SI section 11) |

## Notes

- `section5_6_kinetics/`: the stage notebooks are run in order (1a → 1b → 2–4 → 5 → 6 → 7); each stage reads the outputs of the previous one. Within each experiment folder, `NSxxx-mes.xlsx` (raw measurements) → `NSxxx-setup_reformat.xlsx` (annotated setup: concentrations, pH, speciation) → `NSxxx_fulldata.xlsx` (input to the staged analysis). Stage 6 writes `stage6_k2_high_selection_summary.xlsx`, the interface file for the LFER analysis. The per-well diagnostic fit plots (`*_exp_fit_results.png`, `*_init_fit_results.png`) are not tracked in the repository; they are regenerated by the stage notebooks.
- `section8_lfer/`: both notebooks are deterministic (fixed bootstrap seeds) and reproduce the published parameters exactly. The combined notebook takes ~40 min for 600 Bayesian-bootstrap iterations; reduce `CONFIG.N_BOOT` for a quick test run. `lfer_analysis_v*_metadata.xlsx` contain the full audit trail (inputs, selection history, bootstrap summaries).
- Identifiers: **P5–P9** are the phosphorylating agents of the high-throughput study and **P1–P35** the full set including literature compounds; **Nu1–Nu58** are the nucleophiles (Nu1 = water); **NSxxx** are internal experiment numbers of the screening runs.
- Analyses require Python ≥ 3.10 with `numpy`, `pandas`, `scipy`, `matplotlib`, `openpyxl`, and Jupyter. `.mnova` files require MestReNova; the extracted numerical data used downstream are included as `.xlsx`.
